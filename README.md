# 🧻 AURA FC — ВЗЛОМАН ☠

> Сервер `aura-fc.az` взломан командой Prime FC. Пароль админа был «0:100».

Одностраничный сайт-шутка в стиле хакерского терминала про футбольные команды **Prime FC** и **Aura FC** (а точнее, про то, как вторая проиграла первой).

## Что внутри
- 🎬 Заставка «взлома» с печатающимся терминалом (можно пропустить кликом)
- 🟩 Матричный дождь и эффект старого монитора
- 📂 **71 история**, которые нужно «расшифровать» (с эффектом дешифровки и поиском)
- 🕵️ Досье на 10 игроков
- 📺 Анимированные «камеры» и раздел для гифок (можно добавлять свои)
- 🛒 Чёрный рынок и украденная бухгалтерия
- 💬 Перехваченные чаты и «протокол допроса №666»
- ⌨️ Интерактивный терминал: `help`, `ls`, `cat 5`, `sudo`, `ping gasan`, `rm -rf aura`…
- 📈 Табло и шкала позора, которые растут сами
- 🔥 Реакции на истории (сохраняются в браузере), сортировка по рейтингу, кнопка «скопировать»
- 🎮 Викторина «Угадай героя позора»
- 📅 «Позор дня» — новая история каждый день
- 🔊 Звуки терминала (можно выключить)
- 🥚 Пасхалки: код Konami и 5 кликов по заголовку

Без сборки и зависимостей: чистые HTML, CSS и JavaScript в одном файле.

## Запуск локально
Открой `index.html` в браузере. Или:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Публикация на GitHub Pages
1. Создай репозиторий на GitHub (например `aura-fc-vs-prime-fc`).
2. Залей файлы:
   ```bash
   git init
   git add .
   git commit -m "Aura FC hacked"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/aura-fc-vs-prime-fc.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
4. Через минуту сайт будет по адресу `https://ТВОЙ_НИК.github.io/aura-fc-vs-prime-fc/`.

Автодеплой уже настроен в `.github/workflows/pages.yml`: каждый push в `main` обновляет сайт.
